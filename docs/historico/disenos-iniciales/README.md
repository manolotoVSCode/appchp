# Diseños iniciales

Esta carpeta contiene los planes de diseño previos a la implementación de las fases iniciales del proyecto (v1.x – v2.10 aproximadamente). Son documentos históricos.

Los planes describen funcionalidades que pueden o no estar implementadas hoy, y que pueden haber evolucionado significativamente desde su redacción. No son documentación operativa.

Para entender el estado actual del proyecto, consultar:
- CHANGELOG.md (historial de cambios).
- CLAUDE.md (guía para asistentes y colaboradores).
